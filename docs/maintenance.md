# 新增指标与维护

## 给 Codex 的新增任务模板

> 请在这个已有平台中接入我提供的源文件。先识别地区/对象、日期频率、数值单位、季调与口径断点，保留原始文件和来源。放入「空间名称」；如果主题独立就新建空间。不能覆盖不同口径的官方系列。完成解析和校验、检查图表与单位、生成数据备份，再发布已有网站。

一般CSV可直接从界面导入。Excel/PDF由Codex在本地转换成明确schema的CSV/JSON，或添加可维护的独立适配器。不执行Excel公式、不把PDF中缺失格当0。

## 数据模型

`Dataset`包含`spaces / regions / indicators / sources / observations`。指标用稳定ID；观测为`[YYYY-MM-01, number, source_ref]`。月度和年度分别声明`frequency=M/A`，年度原生观测用该年1月1日表示年度标识，不当作实际1月月度数据。

`unit`是原始单位，`display_divisor`仅用于显示，例如billion除1000显示万亿。`breaks`支持单月date或start/end范围，包含经济定义变化与缺口。来源含原始series ID、链接、提供者、说明；用户上传来源还含R2对象引用。

每次变更先生成完整候选快照，写入R2新对象，然后D1通过`revision`比较并原子替换指针。更新冲突会报409，不能静默覆盖。失败的未引用对象会清理；成功后的旧快照保留便于恢复，未来可按明确保留策略归档。数据量扩大时，升级成按指标分片快照或规范化观测表；保留现有导出契约。

## 适配器

`lib/refresh.ts`中的每条声明绑定一个明确来源/指标。新API需核对精确字段和单位，检查HTTP错误、HTML错误页、空响应、重复月份、非数值、数据缩短与维度变化。已知央行URL由代码构造，不接受用户输入任意抓取地址。

刷新日期动态使用当前日期，排除当月未完成数据。保存原始响应并更新可追溯来源，不删除历史回溯段。FRED价格指数源触发CPI同比与实际利率重算；原始1969指数未收入初始快照，因此保留已核查的1970同比历史。法国与日本已有多来源优先级，不应用OECD过时数据覆盖最新官方段。

新增源的最小fixture包含2行官方数据、表头、预期单位换算与一个坏响应。当前本地网络对部分源超时，真实网络接入状态必须用成功运行记录判断。

## 无人值守调度接入

当前仅有打开页面时每日检查和手动刷新。不能用一个setInterval声称无人值守。当前可调用Sites工具没有创建后台云任务接口，因此未配置后台调度。

未来若宿主提供scheduler：在同一运行环境中调用采集/解析函数与快照服务，按来源串行或小并发执行，设置重试与互斥；执行身份独立于访问者登录。复用同一验证与CAS提交规则，记录attempt/success/latest-period。若迁移到独立Cloudflare Worker，可加scheduled handler和受控cron；需要同时迁移D1/R2绑定及公开访问限制，不能只在Sites生成wrangler文件手加cron并声称生效。

如果使用外部任务请求私有站点，应采用宿主正式服务身份与短期凭证，不保存用户浏览器cookie，不公开刷新URL、不绕过Sites访问控制。完成一次真实成功运行和失败恢复测试后才可把界面状态改为“后台定时已启用”。

## AI与智能体

OpenAI Responses和受控OpenAI兼容HTTP调用位于`app/api/analyze`。只读取所选指标，服务端重新组装上下文，最大180KB；每用户每分钟最多3次且限制输出，不做自动有偿重试。扩展供应商时增加server adapter、明确可接受endpoint、错误映射和测试。

研究JSON与WebMCP均调用`researchContext`。WebMCP只读、随页面注册，浏览器不支持时不影响功能。Codex deep link只预填新任务说明，不自动上传附件或自动发送。无模型密钥可完整使用数据平台和研究包交接。

`OPENAI_API_KEY`应走OpenAI Developers安全密钥流程；兼容提供方使用`AI_API_KEY`托管秘密。设置表只保存非秘密选项。密钥不放上传文件、备份或浏览器存储。

## 检查与发布

1. `node scripts/test-core.mjs`：同月缺口、完整年、适配器单位、坏源、CSV与备份。
2. 启动本地服务后`node scripts/test-api.mjs`：临时创建数据、并发版本锁、幂等、回滚、源文件、恢复、权限、无密钥错误。脚本禁止非localhost目标，并在finally恢复原快照。
3. `npx tsc --noEmit`，Sites构建和发布工具。
4. 检查桌面/手机、图表切换、导入确认、AI交接入口。保留私人访问，邀请邮箱需用户明确提供。

生产备份另包括托管环境配置、D1中settings/runs与R2原始文件。界面的数据备份负责可移植的当前研究数据，不含秘密、上传文件字节或完整历史运行日志。部署前后不要以seed覆写用户已保存的数据。
